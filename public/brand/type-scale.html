House Rules

The conventions that keep pages looking like one site rather than six.

Black, never bold, for headlines

Display type is Montserrat 900. Weight 700 in a headline reads as a different brand.

One pink word per headline

Split the line so the emphasis falls on the payoff — People & Planet Promise. Two pink phrases and neither lands.

Step, don't scale

Sizes jump at 640px and 1024px. No clamp() or vw units — they drift from the scale between breakpoints.

Tight display, relaxed body

Headlines run 0.95 leading, leads 1.25, running copy 1.625. Never the same value for both.

Uppercase gets tracking

Eyebrows 0.3em, kickers 0.22em, buttons 0.05em. Uppercase at default tracking looks cramped.

Caveat is a garnish

One handwritten line per page at most, and only for brand voice — Find your Extraordinary… Never for information.

Figures line up

Any number in a column or next to another number takes tabular-nums.

Measure caps at ~62ch

Prose columns are max-w-3xl. Full-width running text is unreadable on a wide screen.

Sizes verified against the running build — prototype and static HTML agree at every breakpoint.

Tokens live in src/app/globals.css; the static mirror is converted/styles.css.
