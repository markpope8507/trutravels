# Included-as-standard icons

Standalone SVGs for the "Included As Standard" cards on the tour page
(`thailand-island-hopper.html`).

| File | Card |
|------|------|
| `accommodation.svg` | Accommodation (home) |
| `transport.svg` | Transport (van) |
| `meals.svg` | Meals (fork & spoon on a plate) |
| `local-legend.svg` | Local Legend (people) |

All are outline icons, `24×24` on a `0 0 24 24` viewBox, `stroke-width="1.5"`,
stroked in the TruTravels pink **`#FF3F99`** (`--tru-pink`) to match the tour
page. Swap `stroke="#FF3F99"` for `stroke="currentColor"` if you'd rather set the
colour from CSS.
