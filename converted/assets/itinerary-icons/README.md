# Itinerary icons

Standalone SVGs for the "what's included today" rows inside the itinerary
day collapsibles on the tour page (`thailand-island-hopper.html`).

| File | Row |
|------|-----|
| `location.svg` | Location / accommodation (map pin) |
| `transport.svg` | Transport (van — mirrors the Included As Standard transport icon) |
| `inclusion-tick.svg` | Included activity (check) |
| `meals.svg` | Meals (fork & knife — mirrors the Included As Standard meals icon) |

All are outline icons, `24×24` on a `0 0 24 24` viewBox, `stroke-width="2"`,
stroked in the TruTravels pink **`#FF3F99`** (`--tru-pink`) to match how they
render in the itinerary. Swap `stroke="#FF3F99"` for `stroke="currentColor"`
to control the colour from CSS.
